# 🌟 Aesthetic Wallpaper Collection

A curated collection of highly aesthetic anime, lofi, and scenic desktop wallpapers.

---

## 🚀 Quick Start

To install these wallpapers instantly on your system, run the following one-line command:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/sadid56/wallpapers/main/install.sh)"
```

*Or, if you prefer using `wget`:*
```bash
bash -c "$(wget -qO- https://raw.githubusercontent.com/sadid56/wallpapers/main/install.sh)"
```

---

## 🛠️ Installer Details

The installer script (`install.sh`) is designed to safely deploy wallpapers to your local system:

1. **Target Directory**: The wallpapers are installed directly under your home directory at `~/Pictures/wallpapers`.
2. **Directory Initialization**: If `~/Pictures` does not exist, the script creates it automatically.
3. **Smart Backup System**: If `~/Pictures/wallpapers` already exists, the script will back it up to a timestamped folder (e.g., `~/Pictures/wallpaper_backup_YYYYMMDD_HHMMSS`) so you never lose your previous wallpapers.
4. **Copy & Status**: It copies all the wallpapers cleanly and displays detailed copy progress.
