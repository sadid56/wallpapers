# 🌟 Aesthetic Wallpaper Collection

A curated collection of highly aesthetic anime, lofi, and scenic desktop wallpapers. This repository comes with an automated installation script to set up these wallpapers seamlessly on your local environment.

---

## 🚀 Quick Start

To install these wallpapers to your local system, follow these steps:

### 1. Clone the Repository
```bash
git clone <repository-url>
cd Images
```

### 2. Run the Installer
```bash
./install.sh
```

---

## 🛠️ Installer Details

The installer script (`install.sh`) is designed to safely deploy wallpapers to your local system:

1. **Target Directory**: The wallpapers are installed directly under your home directory at `~/Pictures/wallpaper`.
2. **Directory Initialization**: If `~/Pictures` does not exist, the script creates it automatically.
3. **Smart Backup System**: If `~/Pictures/wallpaper` already exists, the script will back it up to a timestamped folder (e.g., `~/Pictures/wallpaper_backup_YYYYMMDD_HHMMSS`) so you never lose your previous wallpapers.
4. **Copy & Status**: It copies all the wallpapers cleanly and displays detailed copy progress.
